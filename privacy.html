Privacy Policy – Thai Dubber Uploader

Last updated: 17 October 2026

Thai Dubber Uploader is a private, internal software tool operated by Korawat Charoenpitaks to upload and manage videos on the operator's own YouTube channel (https://www.youtube.com/@aimemelordz). It is not offered to the public and has no other users.

YouTube API Services

This tool uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service (https://www.youtube.com/t/terms). Google's Privacy Policy applies to data handled by YouTube: https://policies.google.com/privacy.

Data accessed

The tool accesses only the operator's own channel through Google OAuth: it uploads videos, sets thumbnails, manages playlists and reads the status of the operator's own videos. It does not access, collect or store data about other YouTube users or viewers.

Storage

OAuth credentials are stored only on the operator's own computer and are never shared. Video metadata (titles, upload status) is kept locally for operating the channel.

Sharing

No data is sold or shared with third parties.

Revoking access

Access can be revoked at any time via Google security settings: https://security.google.com/settings/security/permissions.
